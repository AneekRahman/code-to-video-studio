# component-reuse-policy

Trigger: Extend the component library.

Inputs: Catalog search, approved scene requirement.

Method: Reuse template, compose components, configure, then justify a new primitive; type inputs; add tests/previews; promote shared changes separately.

Permitted tools: Catalog, source inside producer boundary, typecheck/tests. This instruction grants no tools, credentials or access.

Failure: Major changes return to Showrunner under configured authority.

Exit: Versioned documented capability with evidence, no duplicate copy or hidden shared mutation.

Examples: return a versioned artifact/report for the requested outcome; never claim that a successful command proves creative acceptance.

Evidence: [package tests](../tests/contracts.node-test.ts), [render smoke](../scripts/smoke.ts), and [catalog](../catalog/components.json).
