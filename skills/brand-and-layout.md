# brand-and-layout

Trigger: Configure or apply brand styling.

Inputs: Versioned brand file and pinned font with usage rights.

Method: Use explicit safe margins, palette and caption mode; publish guidance read-only outside private source.

Permitted tools: Brand validator, preview and catalog. This instruction grants no tools, credentials or access.

Failure: No silent system-font substitution; restore pinned asset.

Exit: Exact font hash and brand profile recorded; final brand approval remains separate.

Examples: return a versioned artifact/report for the requested outcome; never claim that a successful command proves creative acceptance.

Evidence: [package tests](../tests/contracts.node-test.ts), [render smoke](../scripts/smoke.ts), and [catalog](../catalog/components.json).
